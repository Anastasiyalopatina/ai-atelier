# ai-atelier

Локальная мастерская памяти проектов и проверяемых исследований для macOS.
Bootstrap: проекты, защищённый локальный сервер, предпросмотр контекста,
реальная синтетическая задача через официальный Codex и сохранение результата.
Полная память, импорт, исследования и MCP — следующие этапы.

## Запуск

Нужны macOS, Node.js **24+**, npm и официальный Codex с входом через ChatGPT.
Docker, Apple Developer и API-ключи не нужны.

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run doctor
npm run build
npm start
```

Launcher открывает браузер с ключом локального сеанса. Не пересылайте эту
ссылку. Backend слушает только `127.0.0.1:4271`. Для первого запуска двойным
кликом выполните `chmod +x ai-atelier.command`. Глобальные настройки Codex и
GitHub не меняются. `npm start -- --no-open` отключает открытие браузера.

`npm run dev` пересобирает frontend при изменениях; обновите страницу вручную.
После изменения backend перезапустите dev.

## Данные и Codex

Данные — в `~/Library/Application Support/ai-atelier`, **вне Git**. Отдельную
директорию можно задать через `AI_ATELIER_DATA_DIR` вне любого репозитория.
Тесты используют временные папки. Авторизация остаётся под управлением
официального клиента; мастерская не читает auth.json и не копирует токены.
При сломанном codex в PATH doctor ищет официальный бинарный файл внутри
установленного ChatGPT. Явный выбор: `AI_ATELIER_CODEX_BIN`.

Перед каждой задачей проверяются ChatGPT-вход и лимиты. Пользователь отдельно
подтверждает отключённые автоматическое платное продолжение и автопополнение;
подтверждение действует 24 часа. Мастерская не управляет аккаунтным биллингом.
Передача модели требует предпросмотра и явного согласия. Сейчас передаётся
только фиксированный вымышленный текст; материалы проекта не отправляются.
Live web search проверен отдельно, но **не подтверждён**: источники не выдумываются.

## Проверки

```sh
npm test
npm run typecheck
npm run build
npm run publish:check
```

Обычные тесты не вызывают модель. Реальные probes запускаются отдельно после
проверки настроек аккаунта:

```sh
npm run smoke:codex -- --confirm-paid-disabled
npm run smoke:web
```

В песочнице Codex может требовать доступ к собственной служебной SQLite вне
проекта, а HTTP-тесты — разрешение loopback. doctor не выводит токены/полный конфиг.
