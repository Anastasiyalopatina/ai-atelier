# Фактическое состояние Bootstrap

Дата проверки: **26 октября 2026, Москва**. Локальный macOS, не облачный прогон.
Статус перед публикацией: **BOOTSTRAP_PUBLICATION_PENDING**.

## Проверено

- macOS 26.6 / arm64, Node v25.9.0, npm 11.13.0, Git 2.50.1; node:sqlite доступен.
- codex из Homebrew PATH (npm-пакет 0.123.0) сломан: отсутствует платформенный
  файл. Найден рабочий официальный Codex внутри ChatGPT: 0.164.0-alpha.11.1.
- Из установленного клиента получены JSON-схемы. App Server stdio: handshake,
  account/read (type=chatgpt), каталог из 7 записей/уровни и лимиты работают.
- Пользователь подтвердил отключённые автопополнение и платное продолжение.
  Подтверждение ручное; приложение не заявляет контроль аккаунтного биллинга.
- Реальный turn на вымышленном «Лунном саде» вернул структурированный расчёт
  7+5=12. JSON проверен кодом, SQLite вне Git, чтение новым процессом успешно.
- Отдельный live web search probe завершён, но событие webSearch не получено.
  Возможность поиска **не подтверждена**, источники не выдумываются.
- npm run build / typecheck пройдены. npm test: 13 тестов пройдены.
  HTTP-тесты требуют разрешения loopback в песочнице; модель они не вызывают.
- Проверены start и dev. Через реальный UI создан вымышленный проект,
  показан предпросмотр, задача завершилась через общую очередь. После остановки
  и запуска нового процесса проект и результат 12 отображаются снова.
- Во встроенном браузере проверен личный аккаунт Anastasiyalopatina;
  GitHub подтвердил доступность имени ai-atelier. Рабочая локальная
  GitHub-авторизация не используется.

## Состав и границы

Каркас React/Vite + Node + SQLite, contracts 1.0.0 / schema 1, защищённый
loopback API, проекты, фиксированный синтетический контекст, предпросмотр,
одобрение, очередь/отмена/идемпотентность/статусы и локальное сохранение.
Пока не реализованы полная память, FTS, импорты/экспорты/backup, research,
настраиваемые роли, реальный MCP. API-заглушки возвращают 501.

## Публикация

Публичны только файлы PUBLIC_FILES.txt; .tools, node_modules, сборка, runtime,
авторизация и данные исключены. Перед публикацией проверяются allowlist,
секреты, staged diff и история. Создание и коммит выполняются через личный
GitHub во встроенном браузере по указанию пользователя.
Финальная ссылка/SHA сообщаются Lead только после проверки опубликованного main.
