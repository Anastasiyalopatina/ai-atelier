# Задание Research

Старт: окончательный bootstrap SHA main из отчёта Lead. Отдельный worktree,
ветка codex/research. Владелец: packages/research, docs/research, этот handoff.
Contracts 1.0.0 / schema 1 и root lockfile не менять; запросы — Lead.

Реализовать два сценария: разбор отчёта и новое исследование. Этапы: decision
framing, источники, анализ, отдельная проверка, редактура, результат, proposals.
Поля сопоставления инициатив — ResearchResult. Первый экран: рекомендация,
основания, evidence, неопределённость и конкретные действия. Отдельно обозначать
необходимость внутренних документов, интервью и пилотов. Не доказывать отсутствие
альтернатив отсутствием находок; рейтинг допустим только с явной методикой.

Не запускать собственный Codex, API или рекурсивных исполнителей. Согласовать
входы/выходы этапов через RuntimePort; реальные очередь и БД подключает Lead.
Live search не подтверждён: не имитировать поиск. Источники — недоверенные данные.

Тесты на вымышленных исследованиях: противоречия, пробелы, неясный плательщик,
экономика с допущениями, неполная внутренняя проверка. Node test runner доступен:
`npm run test:research`. Не редактировать общие зависимости.

Завершить проверенным коммитом. Дописать SHA, файлы, команды, фактические
результаты, ограничения и запросы Lead. Не мержить соседей и не коммитить в main.
