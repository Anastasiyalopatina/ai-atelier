# Задание QA

Старт: окончательный bootstrap SHA main из отчёта Lead. Отдельный worktree,
ветка codex/qa. Владелец: tests/e2e, tests/security, tests/evals, docs/qa,
этот handoff. Не менять contracts/root lockfile/миграции.

Независимо проверить запуск на Mac, restart, изоляцию проектов/evidence,
идемпотентность, отмену, сбой процесса, stale input и будущие proposals.
Проверить Host/Origin/CSRF/DNS rebinding, локальную авторизацию, секреты в
публикации/логах, данные вне Git, injection и запрет local-only контекста /
платного fallback. Для будущих импортов подготовить adversarial fixtures.

Разделять реализованное, заглушки, запланированное и непроверенное. Импорт/SSRF
fetch, полноценные память/research/MCP пока отсутствуют; не объявлять их
проверенными. Только вымышленные данные; никаких материалов компаний.
Обычные тесты — без модели, токенов и платных сервисов.

Начать с npm test, npm run build, npm run publish:check. Реальные probes
не запускать автоматически. В песочнице HTTP-тестам нужно разрешение loopback.

Завершить проверенным коммитом: SHA, файлы, команды/фактические результаты,
дефекты с воспроизведением, ограничения, запросы Lead. Не мержить другие чаты.
