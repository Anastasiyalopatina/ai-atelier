## Что сделано

Рабочий React-интерфейс: первый запуск, выбор/поиск/создание проектов, обзор,
память, before/after с пакетным принятием и конфликтами, источники/версии/
точные основания, постановка исследования, сопоставимый результат, задачи,
предпросмотр и экспорт контекста, настройки. Русский язык, адаптация 360 px,
клавиатура, focus, native dialogs. Решения и результаты выше технических сведений.

Изменены только `apps/web`, `docs/ux`, этот handoff. Общие contracts, backend,
миграции, корневые manifest/lockfile и main не менялись. Новых зависимостей нет.
Полный перечень опубликованных UI-файлов: [PUBLIC_FILES.txt](../ux/PUBLIC_FILES.txt).
Карта экранов и подробный протокол: [UX README](../ux/README.md).

## Реальные подключения

Типизированный `api.ts` использует существующие `/api/status`, `/api/projects`,
`/api/projects/:id/tasks`, `/preview`, `/tasks/:id/cancel` и ручное billing
confirmation. Доменные типы импортированы из contracts v1, HTTP-конверты локальны
до переноса Lead в contracts. Сессионная ссылка, Host/Origin и bearer backend
сохранены. Авторизация Codex, его лимиты и каталог не выдаются за полученные
из `/api/status`: этих полей там пока нет. Вход из UI отключён с объяснением.

Доступны реальные создание/чтение проектов, сохранённые задачи, точный
синтетический предпросмотр, согласие, идемпотентная отправка и запрос отмены.
Результат/отмена показываются по ответу backend. Смена проекта прерывает чтения
и скрывает данные прежнего проекта сразу, до выполнения effect. Ошибки сети
не включают демонстрацию. Ввод формы сохраняется при ошибках.

## Демонстрация и ограничения

Память, proposals, history, импорт текста, переименование/архив, исследование
и экспорт доступны только в явно отмеченном вымышленном demo-режиме.
Изменения живут в памяти вкладки до перезагрузки и не вызывают модель/API.
Исследование открывает заранее подготовленный пример, а не имитирует запуск,
таймер, процесс или новые результаты по изменённой форме.

Local-only материалы и зависимые записи исключаются из demo-экспорта.
Принятие записи не меняет её verification; пакет конфликтует целиком при
устаревшей базе, несовпадении before или пересечении путей. Evidence открывает
конкретный сохранённый фрагмент нужной версии; новая версия помечена отдельно.
Нет фиктивного OCR, процента прогресса, баллов без методики и поисковых находок.

Цель новых demo-проектов можно редактировать; настоящий backend пока позволяет
задать цель при создании. Произвольный импорт/backup/restore/MCP, серверные
черновики, профили ролей и настройки моделей не подключены. Полная интеграция
исследовательского результата и памяти остаётся работой Lead после API.
Завершённость всего приложения не заявляется.

## Проверки

- `npm run build` (включает typecheck) — PASS.
- `node --test apps/web/tests/*.test.mjs` — 22/22 PASS, в том числе SSR component-тесты.
- `npm test` — 13/13 исходных smoke/security PASS с разрешённым loopback.
- `npm run test:ui` — существующая команда является typecheck; component-тесты
  запускаются отдельной командой выше, без изменений root manifest.
- `node apps/web/tests/publish-check.mjs` — PASS: явный allowlist 23 UI-файла,
  проверка staged-содержимого и всей достижимой истории этой ветки.
- Корневой `npm run publish:check` — FAIL по allowlist: он знает только 41 файл
  Bootstrap и обходит также новые commits других ролей через `--all`.
  Совпадений credential/private-path шаблонов не найдено. Корневой allowlist
  должен обновить Lead при общей интеграции, он не менялся этой ролью.
- Lint script в проекте не определён. Новые зависимости для lint не добавлены.
- Встроенный браузер: реальные HTTP create/list/reload/cancel на отдельной
  временной SQLite, синтетический предпросмотр и запрет отправки без billing;
  demo CRUD/архив/восстановление, конфликт/пакет, точное основание, JSON copy/download,
  сохранение вопроса между маршрутами и формы при отключении сервера.
- 1280×720, 390×844, 360×800: длинные названия и цитаты, пустой второй проект,
  отсутствие горизонтального переполнения страницы, focus trap/Escape/возврат.

Использованы только вымышленные данные. Модель в этом UI-проходе не вызывалась;
модельная интеграция и live web search повторно не аттестованы. Скриншоты вне Git
показывают отдельные проверенные состояния, а не приёмку всего приложения.

## Запуск QA-preview

```sh
npm run build
node apps/web/tests/serve.mjs
```

`http://127.0.0.1:4283/?demo=1` — отдельный временный вымышленный preview.
Ctrl+C закрывает сервер и удаляет только его временные данные. Обычный
пользовательский запуск — `npm run dev` через launcher после интеграции UI.
