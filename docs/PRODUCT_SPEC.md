# ai-atelier — продукт, v1

Цель: сохранять контекст изолированных проектов и помогать принимать решения
на основе проверяемых исследований. Приоритеты — память и исследования.
Оркестрация нужна для их исполнения, а не как отдельный продукт.

Память V1: цели, ограничения, текущая картина, источники/фрагменты, утверждения,
гипотезы, расчёты, решения, вопросы, инициативы, исследования, следующие действия.
Тип знания и проверка различаются; модельный вывод не становится фактом.
Источники: origin, даты, версия/хеш и устойчивые фрагменты. Evidence ссылается на
конкретный фрагмент. Расчёт содержит формулу, входы, единицы и допущения.

Изменения памяти — предложения с diff и историей. Устаревшая версия вызывает
конфликт. Новый источник помечает зависимые выводы для пересмотра, не переписывая
историю. Экспорт контекста нового чата — адресная выборка с задачей, решениями,
ограничениями, evidence, пробелами и действиями; версия, время, предпросмотр,
выбор объёма и исключённые материалы обязательны. План: JSON/Markdown, backup/restore.

План импорта: текст, Markdown, текстовые PDF/DOCX, CSV/XLSX с листом/диапазоном.
Без OCR, исполнения макросов и платных внешних парсеров. Сканы, пароли,
повреждённые и неподдерживаемые файлы получают понятное ограничение.

Исследования: разбор отчёта и новое исследование. Этапы: постановка решения →
источники → анализ → независимая проверка → редактура → результат → proposals.
Сравнение инициатив описывает потребителя/плательщика, внутренние аналоги и
объём проверки, рынок/альтернативы, механизм ценности, метрики/контрметрики,
данные/ограничения, экономику/допущения, MVP-эксперимент, критерии продолжить /
изменить / остановить, риски, неизвестное и действия. Первый экран — краткая
рекомендация и основания; затем сопоставимые карточки и раскрываемые evidence.
Рейтинги без методики запрещены. Отсутствие находки не доказывает отсутствие
решения. Внутренний документ, интервью или пилот обозначаются как следующий шаг.

## Bootstrap

Реализованы проекты, схема SQLite v1, предпросмотр синтетического контекста,
явное одобрение, одна очередь и реальное выполнение через Codex. Есть статусы,
отмена, идемпотентность, обнаружение прерывания и сохранение результата.

Пока не реализованы общие операции памяти/proposals, FTS, импорт/экспорт/backup,
методика research, полноценный UI, настраиваемые роли и MCP. Их API явно
возвращают 501. Заглушки не выдают себя за готовый продукт или реальный поиск.
