# Приёмка Bootstrap

BOOTSTRAP_READY допустим только после всех обязательных проверок:

- Среда/версии проверены на Mac без секретов; официальный App Server подтвердил
  managed ChatGPT. Каталог и уровни получены поддерживаемым интерфейсом.
- Пользователь проверил отключённое платное продолжение. Реальный turn на
  вымышленных данных завершён; JSON проверен, сохранён вне Git и прочитан
  новым процессом. Live search проверен отдельно, ограничение показано.
- doctor/dev/test/build/start и launcher доступны. Frontend/backend запускаются.
  Есть проверки restart, изоляции, идемпотентности, stale input, loopback,
  Host/Origin и авторизации. Тесты используют отдельные временные папки.
- Contracts 1.0.0 / schema 1 зафиксированы. Research/MCP явно не реализованы;
  заглушки не подменяют продукт. Общая модельная очередь ограничена.
- Allowlist, проверка секретов, staged diff и истории. Публикуются только
  исходники, очищенные документы и вымышленные примеры.
- Подтверждён новый публичный Anastasiyalopatina/ai-atelier, указан точный SHA
  main и исходная точка трёх worktree-чатов. Их задания лежат в handoffs.

Обычные тесты — без модели, ключей и платных сервисов. Каталог не доказывает
модельный доступ; «не проверено» не равно «ошибок нет». Независимая QA-приёмка
полного продукта остаётся следующим этапом.
