# Интерфейс ai-atelier

UI-ветка от Bootstrap `9d4a992227b682f92b665fcae9c0bb7b0e52a2a2`.
Русская мастерская для решений, памяти и исследований. Системный шрифт для
управления, Georgia для заголовков, спокойные зелёные акценты, без внешних
шрифтов, изображений, аналитики и новых зависимостей. Малые линейные иконки
нарисованы в проекте; сторонние ассеты не используются.

## Как посмотреть

Обычный режим: `npm run build`, затем `npm run dev` из UI-worktree. Launcher
откроет локальный сеанс. Если порт 4271 занят уже запущенной мастерской,
не останавливайте чужой процесс; используйте отдельный QA-preview ниже.

```sh
npm ci --offline --cache /private/tmp/ai-atelier-npm-cache --ignore-scripts --no-audit --no-fund
npm run build
node apps/web/tests/serve.mjs
```

Offline-install требует уже заполненного локального npm-cache. На другой машине
используйте обычный `npm ci --ignore-scripts --no-audit --no-fund`.

Откройте `http://127.0.0.1:4283/?demo=1`. Preview создаёт временную вымышленную
SQLite вне Git и удаляет её при Ctrl+C. Пользовательская БД не читается.
Модель не вызывается. В тестовую БД напрямую добавлены две задачи: пример
сохранённого результата и ожидающая задача для проверки отмены. Это fixtures,
а не результат нового модельного запуска. Подтверждение расходов не создаётся.
Локальная ссылка сеанса хранится в приватном файле ОС вне Git и не печатается.

## Экраны

- Первый запуск: локальное хранение, границы передачи контекста, создание
  проекта, явный вход в демонстрацию. Недоступный backend не подменяется моками.
- Обзор: цель, текущая картина, решения, открытый вопрос, ближайшие действия,
  изменения памяти и рекомендация из демонстрационного разбора.
- Память: поиск, типы и независимые статусы проверки, точное основание,
  подробности расчёта и история принятых редакций.
- Предложения: before/after, явный выбор пакета, проверка версии и before-text,
  конфликт без частичного применения, новый diff с повторным выбором.
  Принятие редакции не меняет verification.
- Источники: поиск фрагментов, версии, доступность Codex/local-only,
  отдельный демонстрационный переключатель интернет-запросов. Вставка текста
  и чтение UTF-8 TXT/Markdown до 128 КБ в этой вкладке; ошибки остальных
  форматов, сканов и кодировки объяснены. Нет фиктивного извлечения PDF/OCR.
- Исследование: два сценария, вопрос, 2–3 инициативы, источники, глубина,
  ограничения и точный контекст. Кнопка открывает явно обозначенный заранее
  подготовленный результат, который не зависит от правок формы.
- Результат: рекомендация, основания, таблица инициатив, определения метрик,
  контрметрики, экономика с допущениями, MVP, критерии решений, неизвестное
  и действия. Нет баллов без методики или выдуманных поисковых источников.
- Ход работы: очередь, результаты, реальные состояния и время, запрос отмены
  с ожиданием ответа сервера. Технические сведения раскрываются отдельно.
  Процент выполнения не вычисляется по таймеру.
- Передача контекста: выбор объёма, Markdown/JSON, предпросмотр, копирование,
  скачивание, версия/дата/хеш и число исключений. Local-only источники и записи,
  ссылающиеся на них, исключены вместе. Это экспорт только demo-памяти.
- Настройки: backend отдельно от Codex; неизвестные авторизация, каталог и
  лимиты подписаны. Два флажка ручного подтверждения расходов. Не реализованные
  вход, каталог, роли, директория и backup объяснены рядом с отключённым действием.

## Состояние и безопасность

Обычный режим читает проекты и задачи из backend при открытии. Демо включается
только явно или через `?demo=1`, заметно подписано на каждом экране и сбрасывается
при перезагрузке. Источники и исследование в нём полностью вымышлены. Демо-операции
не вызывают API и модель. Проверка настоящего Codex остаётся отдельным сценарием
с точным синтетическим предпросмотром и согласием.

Доменные сущности импортированы из contracts v1. В `api.ts` описаны только
локальные HTTP-конверты уже существующих endpoints. Они проверяются на входе;
коды ошибок переводятся без отображения необработанного содержимого сервера.
Сессионный fragment удаляется из адреса и сохраняется только для вкладки.

Один синхронный ref блокирует повторную отправку до rerender. Идемпотентный ключ
сохраняется при неоднозначной ошибке отправки; новый ключ создаётся только после
нового предпросмотра. Смена проекта отменяет чтение и проверяет lifetime запроса;
список задач дополнительно фильтруется по projectId непосредственно при выводе.
Демонстрационные формы исследования разделены по проектам и переживают смену
маршрута. Формы создания сохраняют ввод при ошибке. Несохранённые черновики
существуют в памяти вкладки до перезагрузки; серверного хранения черновиков нет.

Native dialog дополнен обходом focus, Escape и возвратом focus на открывшее
действие. Есть skip-link, названия полей, текстовые статусы, видимый focus,
семантическая таблица и отдельный горизонтальный скролл таблицы/навигации
на узком экране. Длинный текст переносится; drawer прокручивается самостоятельно.
Содержимое источников выводится React-текстом, без raw HTML.

## Фактическая проверка · 26 октября 2026

- `npm run build` — пройдено, включает общий typecheck.
- `node --test apps/web/tests/*.test.mjs` — 22/22. Есть SSR component-тесты
  настоящих Memory, ProposalDialog, Settings и Research через установленный Vite;
  проверки конфликтов, доказательств, раскрытия, HTTP-ошибок и отмены запросов.
- `npm test` — исходные 13/13 smoke/security. В песочнице нужен доступ loopback;
  модель эти тесты не вызывают. Отдельной lint-команды в manifest нет.
- Встроенный браузер, 1280×720: переходы, вопрос после смены экрана, выбор
  пакета, конфликт/новый diff, история, точный фрагмент старой версии,
  переименование/архив/восстановление demo-проекта, поиск проектов.
- Окна 390×844 и 360×800: длинное русское название, пустая память другого
  проекта и цитата 1432 символа с длинной неразрывной строкой. Ширина документа
  совпала с viewport, переполнения страницы нет.
- Клавиатура: Shift+Tab удерживается в диалоге, Escape закрывает его и возвращает
  focus на исходную кнопку. Это ручная проверка, не полный аудит screen reader.
- Настоящий HTTP backend на отдельной временной БД: создание проекта и поиск
  после перезагрузки страницы; отмена seeded queued-задачи подтверждена backend;
  предпросмотр реального Bootstrap-текста и заблокированный запуск без billing.
- Сервер остановлен во время заполненной формы: ошибка сети видна, оба поля
  сохранены, демонстрация не включилась. Тестовый backend затем запущен заново.
- JSON скопирован и фактически скачан; файл разобран, схема 1, хеш 64 символа,
  local-only источник отсутствует. Markdown проверен unit-тестом и предпросмотром.

Скриншоты вымышленных состояний сохранены локально вне Git: обзор и пустой
проект в узком окне, длинное основание, конфликт, результат исследования и
ошибка сети с сохранённой формой. Пользовательская БД, email, токены и реальные
документы на скриншотах не используются. Эти проверки не подтверждают полный
продукт, повторный реальный модельный цикл или live web search.
